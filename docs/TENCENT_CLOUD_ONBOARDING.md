# 腾讯云个人主体上线操作清单

适用范围：帧足记 VoyaFrame 以个人主体首次在腾讯云完成域名注册、ICP 备案和中国大陆上线。

> 身份证照片、验证码、账号密码、AccessKey 和 SecretKey 只在腾讯云或工信部官方页面填写，不能发送给开发人员，也不能写入项目文件。

## 推荐的第一阶段架构

```text
已备案域名 → 腾讯云轻量应用服务器（上海）→ Nginx → 帧足记 VoyaFrame dist/
```

第一阶段使用轻量应用服务器，是因为它可以作为腾讯云首次备案所需的云资源，当前纯静态网站也可以直接部署在上面。备案通过后，再按访问量升级为“域名 → CDN → COS 静态网站”。

## 一、注册并实名认证腾讯云账号

1. 打开 [腾讯云官网](https://cloud.tencent.com/)，使用本人长期持有的手机号注册或登录。
2. 进入账号中心完成“个人实名认证”。
3. 实名姓名必须与后续域名所有者、ICP 备案主体及本人证件完全一致。
4. 开启登录保护和多因素认证。

不要使用他人、单位或学校的主体完成实名认证，否则后续域名和个人备案主体可能不一致。

## 二、创建域名实名信息模板

1. 打开腾讯云“域名注册控制台”。
2. 进入“信息模板”或“域名信息模板”。
3. 新建模板，所有者类型选择“个人”。
4. 按官方页面填写本人真实信息并提交实名认证。
5. 等待模板状态变成“实名审核通过”后再购买域名。

域名注册时必须选择已经实名审核通过的信息模板。

## 三、选择域名

建议优先查询以下思路，不代表当前一定可注册：

- `travelmotion.cn`
- `travelmotion.com`
- `travelmotionapp.cn`
- `mytravelmotion.cn`
- 简短、可读的品牌拼音 `.cn`

选择原则：

- 首选 `.cn` 或 `.com`。
- 不要购买腾讯云文档明确提示无法备案的 `.org`、`.name` 等后缀。
- 避免连字符、难拼写单词和过长域名。
- 避免包含他人商标、平台名称或可能误导为政府、学校、机构的词。
- 检查首年价格和续费价格，谨慎购买高价溢价域名。

如果预算允许，可以同时保护 `.cn` 和 `.com`，但第一阶段只需选择一个作为主域名。

## 四、购买域名

1. 在腾讯云“域名注册”页面搜索完整域名。
2. 确认拼写、后缀、首年价格和续费价格。
3. 加入购物车并选择已通过实名认证的个人信息模板。
4. 推荐购买 2–3 年并开启自动续费。
5. 建议开启禁止转移锁；是否开启禁止更新锁按腾讯云页面说明决定。
6. 核对域名所有者必须是本人真实姓名。
7. 支付并在“我的域名”确认注册状态和实名认证状态。

域名属于即时注册产品。腾讯云提示注册成功后不能修改且不能退款，因此支付前必须再次检查拼写。

域名实名认证通过后，腾讯云文档要求等待满 3 个自然日，让实名数据同步到工信部，再提交 ICP 备案。

## 五、购买备案云资源

推荐购买腾讯云轻量应用服务器（Lighthouse）：

| 选项 | 建议值 |
|---|---|
| 地域 | 上海（中国大陆） |
| 镜像 | Ubuntu LTS |
| 计费 | 包年包月 |
| 时长 | 建议 1 年 |
| 配置 | 入门配置即可，建议不低于 2 核 2 GB |
| 公网网络 | 必须有公网 IP，带宽不能为 0 |

腾讯云当前规则要求：用于备案的中国大陆轻量应用服务器须为包年包月，累计购买时长不少于 3 个月，备案期间剩余有效期不少于 1 个月，并具有公网 IP 和非零带宽。

暂时不要购买：

- 中国香港或境外地域服务器：不能作为中国大陆 ICP 备案资源；
- 按量计费或试用服务器：不能作为该备案资源；
- 昂贵的数据库、GPU 或高配置服务器：当前纯静态站用不到；
- 单独为了备案购买 COS：COS 静态托管不等同于备案云资源。

## 六、提交首次 ICP 备案

域名实名信息同步完成、轻量服务器满足条件后：

1. 进入腾讯云“ICP 备案”控制台或腾讯云备案小程序。
2. 选择“开始备案”或“首次备案”。
3. 备案性质选择“个人”。
4. 应用服务类型选择“网站/域名”。
5. 备案主体姓名、证件、腾讯云实名和域名所有者必须一致。
6. 选择刚购买的中国大陆轻量应用服务器作为备案云资源。
7. 按本人证件所在地和属地管局规则填写。
8. 网站服务如实描述为个人旅行路线动画工具，不填写尚未提供的新闻、社交、支付、医疗、教育培训等服务。
9. 按腾讯云小程序指引完成证件原件拍摄、视频核验及材料提交。
10. 腾讯云初审通过并提交管局后，及时完成工信部短信核验。

备案审核期间不要提前通过中国大陆服务器公开访问未备案域名。

## 七、备案通过后的项目配置

获得备案号后，在项目根目录复制并填写：

```powershell
Copy-Item .env.production.example .env.production
```

```dotenv
VITE_SITE_URL=https://你的正式域名
VITE_PUBLIC_BASE=/
VITE_OPERATOR_NAME=对外公示的运营者名称
VITE_CONTACT_EMAIL=jjunzhe@zju.edu.cn
VITE_ICP_NUMBER=管局下发的完整备案号
VITE_PUBLIC_SECURITY_NUMBER=
VITE_PUBLIC_SECURITY_URL=
```

然后运行：

```powershell
npm ci
npm run verify:release
```

## 八、部署到轻量应用服务器

备案通过后再执行：

1. 将域名解析到轻量应用服务器公网 IP。
2. 在服务器安装 Nginx。
3. 将 `dist/` 上传到 Nginx 网站目录。
4. 根据 `deploy/nginx.conf` 配置静态网站。
5. 申请并部署 HTTPS 证书。
6. 只开放必要端口：SSH、HTTP、HTTPS；SSH 最好限制来源并使用密钥登录。
7. 测试通过后开启 HTTP 到 HTTPS 跳转。

具体命令应在服务器系统、域名和证书确认后生成，不应在购买前照抄不匹配的命令。

## 九、公安备案和后续处理

网站开通并取得 ICP 备案号后，按照腾讯云和属地公安机关要求及时办理公安联网备案。完成后将公安备案号和官方链接填入 `.env.production`，重新构建发布。
