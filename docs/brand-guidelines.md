# 帧足记 VoyaFrame 品牌与界面规范

## 品牌定位

帧足记是一款旅行路线纪录与动画制作工具。界面应像成熟的创作工作台：安静、可信、内容优先，不使用“AI 生成器”常见的星芒、霓虹渐变、泛滥发光和夸张宣传语。

## Logo

标记由圆角画面帧和连接两个地点的旅行路径组成，表达“把一段旅程放进画面”。

- 页头使用标记、中文名和英文名的横向组合。
- Favicon、PWA 图标和小尺寸空间使用标记本身。
- 标记使用单色，不添加渐变、阴影、旋转或描边特效。
- 图标最小尺寸为 24px；完整组合最小宽度为 120px。
- 标记四周至少保留一个标记高度的净空。

## 色彩

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| App background | `#071019` | 地图外的最深背景 |
| Panel | `#0A141D` | 编辑器、时间轴、弹窗 |
| Surface | `#101B24` | 输入框、地点卡片 |
| Border | `#21303C` | 分隔与边框 |
| Primary text | `#EDF2F3` | 标题和主要内容 |
| Secondary text | `#98A8B3` | 说明和辅助信息 |
| Faint text | `#748692` | 次要元数据，保持小字号 AA 对比度 |
| Route blue | `#9BD7E1` | 主操作、路线和地点 |
| Arrival gold | `#D8B477` | 当前目的地、到达状态 |
| Danger | `#E38A8A` | 删除与录制异常 |

颜色通过 `src/index.css` 中的语义变量使用。除地图主题绘制外，组件中不新增任意渐变。

## 字体与层级

- 使用系统无衬线字体栈，中文优先 `PingFang SC` / `Microsoft YaHei`，不加载阻塞渲染的远程字体。
- 正文和控件默认 14–16px，辅助文字不小于 12px。
- 标题通过字号、字重和间距建立层级，不依赖全大写或过度字距。
- 时间、序号等变化数字使用等宽数字。

## 图标与交互

- 结构性图标统一使用 `src/components/Icon.tsx` 的 1.8px 圆角单线 SVG。
- 不使用 emoji、字体符号或混合图标库。
- 手机触控区域不小于 44×44px，相邻操作至少保留 8px 可辨识间距。
- 微交互使用 150–300ms，改变颜色或透明度，不通过位移制造跳动。
- 每个界面只保留一个主按钮；导出、重播等操作使用次级样式。
